01

Course Description

This course provides students with an opportunity to explore creativity and computational thinking by designing and developing micro-games in C. Students will learn how to transform simple ideas into interactive games by applying fundamental programming concepts, designing game mechanics, implementing game logic, and developing engaging user interactions.

The course follows a project-based learning approach in which students conceptualise, prototype, develop, test, and showcase their original micro-games. Emphasis will be placed on creativity, logical reasoning, algorithmic thinking, and effective application of C programming concepts.

Key Deliverable & Milestone

Teams will maintain a documented GitHub repository from initial Game Design Document (GDD) through tagged final release and live demonstration.

02

Course Objectives

The primary objectives of this Winter School are to:

  1. 1 Introduce students to fundamental game design principles and gameplay mechanics.
  2. 2 Encourage creative thinking and innovative problem-solving through game development.
  3. 3 Enable students to apply C programming concepts to develop interactive applications.
  4. 4 Develop skills in algorithm design, program structuring, debugging, and testing.
  5. 5 Provide hands-on experience in developing and presenting original micro-games.
03

Detailed Curriculum & Hour Distribution

15-hour structured progression from game design and Git setup to C implementation and exhibition.

Hrs Topics Activities Expected Outcome
1 Introduction to Game Design: Game mechanics, objectives, rules, challenges, rewards, and player interaction. Explore simple games such as Tic-Tac-Toe, Nim, Hangman, and Number Guessing. Analyse their underlying logic. Understanding fundamental game design principles.
2 Introduction to Git and GitHub: Version control, repositories, commits, cloning, pushing, and pulling. Create GitHub accounts, configure Git, create a repository, and upload a simple C program. Familiarity with Git and GitHub fundamentals.
3 Creative Game Ideation: Brainstorming, identifying game themes, defining objectives, rules, and winning/losing conditions. Brainstorm at least three original game ideas and select one for development. Selection of an original game concept.
4 Game Design and Mechanics: Gameplay flow, scoring, difficulty levels, and player interaction. Prepare a Game Design Document (GDD) and create a GitHub repository for the project. Finalized game concept and project repository.
5 Algorithm Design: Problem decomposition, pseudocode, flowcharts, game states, and game logic. Develop the algorithm and flowchart. Upload the design document and algorithm to GitHub. Documented implementation plan.
6 Implementing Game Logic Using C: Conditional statements, loops, user input, and random number generation. Implement the basic gameplay mechanism and commit the initial prototype. Initial playable game prototype.
7 Collaborative Programming Using GitHub: Branching, merging, pull requests, code reviews, and merge conflict resolution. Each team member creates a feature branch, implements a small feature, and submits a pull request for review. Experience with collaborative development workflows.
8 Modular Game Development: Functions, parameter passing, return values, and modular programming. Divide game functionality among team members and implement independent modules. Modular C implementation.
9 Data Management in Games: Arrays, strings, structures, and pointers. Incorporate suitable data structures into the game. Integrate contributions from team members. Improved game implementation.
10 Game Development Studio – I: Advanced game mechanics, scoring, multiple rounds, difficulty levels, and random events. Implement additional gameplay features using separate Git branches. Enhanced game functionality.
11 Game Development Studio – II: Integration, error handling, user interaction, and file handling. Review and merge contributions, resolve conflicts, and complete the game. Feature-complete micro-game.
12 Game Testing and Debugging: Functional testing, boundary conditions, invalid inputs, and logical errors. Peer testing, reporting bugs through GitHub Issues, and tracking their resolution. Tested game with documented issues.
13 Game Refinement and Finalization: Incorporating feedback, balancing difficulty, and improving user experience. Final code review, bug fixes, documentation, and release of the final version using a GitHub release or tagged commit. Finalized and documented micro-game.
14 Game Showcase – I: Demonstration of games and explanation of game mechanics, algorithms, and C programming concepts. The first group of students demonstrates their games. Technical demonstration.
15 Game Showcase – II: Remaining demonstrations, peer gameplay, evaluation, and reflection. Micro-Game Exhibition and People's Choice Award. Final project presentation.
04

Suggested Final Project Guidelines

Each student or team (atmost 3 students) must develop an original micro-game subject to the following guidelines:

Guideline 01 Language

The game must be implemented using the C programming language.

Guideline 02 Structure

The game should have a clearly defined objective and set of rules.

Guideline 03 Playtime

The game should be playable and completable within approximately 2–5 minutes.

Guideline 04 Code Quality

The implementation should demonstrate appropriate use of C programming concepts.

Guideline 05 Creativity

The game should incorporate at least one interesting or innovative gameplay mechanic.

Guideline 06 Viva / Demo

Students must be able to explain the underlying algorithm and implementation.
